# STARBUCKS-DESCRIPITIVE-ANALYTICS
A descriptive analytics project on Starbucks sales data to analyze sale trends, product performance, and key business insight using data visualization.
Project Title

Starbucks Sales Data Analysis Using Descriptive Analytics

Project Description

This project focuses on analyzing Starbucks sales data using Python, Pandas, and Data Visualization techniques. It examines daily and monthly sales trends, product performance, category-wise revenue, store-wise sales, and payment methods to identify business insights and support data-driven decision-making.

Objectives

1. Analyze daily and monthly sales trends.
2. Identify the highest-selling product.
3. Compare Beverage and Bakery sales.
4. Evaluate sales across Mumbai, Delhi, Lucknow, and Bengaluru.
5. Analyze customer payment preferences.
6. Provide business recommendations based on the results.

Technologies Used

- Python
- Pandas
- Data Visualization
- CSV Dataset
- Descriptive Analytics

Expected Outcome

To identify sales patterns, top-performing products, high-performing stores, and opportunities for improving business performance.


# RetailPulse Sales and Customer Analytics Using IBM Cognos Analytics

## 1. Project Overview

This project demonstrates the use of IBM Cognos Analytics to create sales reports, apply data filters, analyze retail performance, and visualize customer insights using the RetailPulse dataset.

## 2. Project Objectives

- Create and format sales reports.
- Group sales data and calculate summary totals.
- Apply region and date filters.
- Create crosstab reports to compare sales across regions and product categories.
- Build a customer insights dashboard.
- Use interactive filters to analyze customer data.

## 3. Tools and Technologies Used

- **IBM Cognos Analytics:** For creating reports, crosstabs, and dashboards.
- **RetailPulse Sales Package:** For sales reporting, grouping, filtering, and product analysis.
- **RetailPulse Customers Data Module:** For customer analysis and dashboard visualization.

## 4. Practicals Covered

### Practical 1: Generate a First RetailPulse Report
Create a basic list report containing Region, Product Category, and Sales Amount using the RetailPulse Sales package.

### Practical 2: Build a Grouped RetailPulse Sales List Report
Group sales data by Region and Store Name, format Sales Amount as currency, and calculate summary totals.

### Practical 3: Filter RetailPulse Sales by Region and Date
Apply a Region filter and a date-range filter using the AND operator. Convert the Region filter into a prompt to make the report reusable.

### Practical 4: Build a RetailPulse Region × Product Crosstab
Create a crosstab with Region as rows and Product Category as columns. Display Sales Amount and Quantity with row and column summary totals.

### Practical 6: Build the RetailPulse Customer Insights Dashboard
Create a dashboard containing:
- A summary card for active customers.
- A line chart comparing new and returning customers over time.
- A bar chart showing customers by loyalty segment.
- A Region filter that updates the dashboard widgets.

## 5. Key Concepts

- List report creation
- Data grouping and formatting
- Sum aggregation and summary totals
- Simple and advanced detail filters
- AND conditions and prompted filters
- Crosstab reports and multiple measures
- Dashboard cards and charts
- Interactive filtering and customer analytics

## 6. Expected Learning Outcomes

By completing these practicals, learners develop skills in report creation, data filtering, sales analysis, data aggregation, crosstab reporting, and interactive dashboard design using IBM Cognos Analytics.
